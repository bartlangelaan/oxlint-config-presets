# Contributing

This is a pnpm workspace monorepo. Install dependencies once at the root:

```sh
pnpm install
```

Before committing, run:

```sh
pnpm before-commit
```

For details on contributing to a specific package, see that package's own `CONTRIBUTING.md`:

- [`packages/oxlint-config-presets`](packages/oxlint-config-presets/CONTRIBUTING.md)
